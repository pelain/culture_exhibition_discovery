# DK Factory 다른 앱 목록 (apps.json)

네 앱(물방울 알림, 동네에서 뛰자, 길위로, 한국을 보다)의 설정 화면 "DK Factory의 다른 앱" 카드가 하루에 한 번 `../apps.json` 을 받아 쓴다.

- 새 앱 추가: `apps` 에 한 줄 넣고 아이콘(정사각 PNG, 144px 쯤, 512KB 이하)을 이 폴더에 둔다. 앱 업데이트 없이 다음 날부터 카드에 나온다.
- 잠시 숨기기: `published` 를 `false` 로.
- 지켜야 할 모양: `version` 은 1, `key` 는 영문 소문자·숫자·`_`, `name` 의 `ko`·`en` 은 꼭 있어야 한다, `icon` 은 `https://` 주소.
  모양이 틀리면 앱은 이 파일을 무시하고 마지막으로 받은 목록(없으면 앱에 든 목록)을 쓴다.
- 자기 자신은 각 앱이 알아서 뺀다.
- 받는 코드: 각 앱의 `engage/RemotePromo.kt`.
